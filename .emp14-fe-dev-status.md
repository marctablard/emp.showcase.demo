## Architektur-Entscheidung
- Cache = reines **server-only-Modul** (globalThis-backed), **kein DI** → kein
  `npm run generate`, keine Container-Regeneration.
- Adapter liefert nur Provider-Primitive (`validateWebhookSignature`,
  `mapWebhookPayload`); die **Facade** (`DelegatingCmsServiceSSR`, Service-Layer)
  orchestriert `handleWebhook` + Read-Caching + Invalidierung. Adapter bleibt
  cache-agnostisch, keine Integration→Service-Konkret-Kopplung über den Cache.
