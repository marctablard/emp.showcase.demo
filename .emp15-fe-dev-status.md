## Architektur-Entscheidungen (FE-Lead, vor Implementierung getroffen)

| Thema | Entscheidung | Begründung |
|---|---|---|
| SPI-Split | `CmsPreviewDetector` (edge-safe, sync) ⊂ `CmsPreviewAdapter` (node-only, `renderPreviewPage`) | Interface Segregation; Edge-Bundle frei von SDK |
| Detector-Registry | `getPreviewDetector(env)` **ohne** `server-only`, importiert nur die *pure* `storyblok-preview-detection.ts` | Edge-Bundle bleibt `@storyblok`-frei |
| Adapter-Registry | `getPreviewAdapter(env)` **mit** `server-only`, DI-Resolve `CmsPreviewAdapter:storyblok` | Node-only SDK-Pfad |
| Provider-Cases | Switch exhaustiv über **reale** `CmsProviderId`-Union `'storyblok'\|'local'\|'none'` (nicht `'mock'`) | `CmsProviderResolver` ist Source of Truth; `mock` → unknown → `none` → Preview 404 |
| Validierungs-Split | Detector (edge): Presence + Timestamp · Adapter (node): + Space-ID-Match | Space-ID braucht Config/`getSpaceId()` → node-seitig |
| Space-ID-Quelle | neue Env `NEXT_PUBLIC_STORYBLOK_SPACE_ID`, `getSpaceId(): string\|null`; bei `null` Step 3 mit Warn überspringen | FU-004-konformes Restrisiko, kein Hard-Fail bei fehlender Config |
| `PREVIEW_ROUTE_PREFIX` | `'/preview'` als einzige Pfad-Präfix-Quelle, exportiert aus Detector-Registry | Anker-Vorgabe |
| Middleware | `src/site/middleware.ts` reicht `/preview/...` durch (kein Site-Rewrite), `no-store` bei echtem Preview-Request via Detector | Top-Level-Route außerhalb `[site]/[locale]` |
